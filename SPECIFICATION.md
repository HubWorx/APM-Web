# APM Value Calculator - Product Specification

## Overview

**Product Name:** AI-Powered APM Value Calculator
**Purpose:** Interactive web application that guides users through understanding different Asset Performance Management (APM) approaches and calculates ROI for their organization
**Target Audience:** Oil & Gas and Power Generation industry decision-makers
**Last Updated:** 2026-01-18

---

## Website Flow

### 6-Step Journey

1. **Industry Selection** - User chooses their industry
2. **Traditional ISO 55000 Approach** - Shows old methodology (4-5 years)
3. **Disruptive Technology Companies** - Showcases AI-powered APM vendors
4. **Holistic Asset Intelligence** - Presents combined approach (18 months)
5. **Comparison** - Side-by-side charts and case studies
6. **ROI Calculator** - Personalized financial impact calculation

## Calculation Formulas

### Traditional Approach
```
Profit Gain = Profit × (Traditional ROCE% ÷ 100)
Maintenance Savings = Maintenance × 0.15
Total Value = Profit Gain + Maintenance Savings
```

### Health-Centric Approach
```
Profit Gain = Profit × (Health-Centric ROCE% ÷ 100)
Maintenance Savings = Maintenance × 0.30
Total Value = Profit Gain + Maintenance Savings
```

### Holistic Approach
```
Profit Gain = Profit × (Holistic ROCE% ÷ 100)
Maintenance Savings = Maintenance × 0.40
Total Value = Profit Gain + Maintenance Savings
```

### Holistic Advantage
```
Advantage = Holistic Total Value - Traditional Total Value
```

## Navigation Logic

### State Management
```javascript
// Global variables
let currentIndustry = null;  // 'oilgas' or 'powergen'
let charts = {};              // Store chart instances
```

### Step Transitions
1. **Step 1 → Step 2:** `selectIndustry(industry)`
   - Stores industry selection
   - Loads industry-specific data
   - Renders Chart 1
   - Displays industry badge

2. **Step 2 → Step 3:** `goToStep3()`
   - Simple navigation
   - No data loading

3. **Step 3 → Step 4:** `goToStep4()`
   - Simple navigation
   - No data loading

4. **Step 4 → Step 5:** `goToStep5()`
   - Loads comparison data
   - Renders Chart 2 and Chart 3
   - Uses stored industry selection

5. **Step 5 → Step 6:** `goToStep6()`
   - Simple navigation
   - Calculator ready for input

6. **Calculate:** `calculate()`
   - Validates all inputs
   - Performs calculations
   - Updates result displays
   - Shows results section

7. **Restart:** `location.reload()`
   - Reloads entire page
   - Clears all state

### Helper Functions
- `hideAll()`: Hides all 6 steps
- `drawChart(canvasId, data, showLegend)`: Renders Chart.js chart
- `window.scrollTo(0,0)`: Scrolls to top on each transition

## Error Handling

### Input Validation
```javascript
// Check for positive values
if (rev <= 0 || cap <= 0 || prof <= 0 || maint <= 0) {
    alert('Please enter valid positive values for all fields.');
    return;
}

// Check for industry selection
if (!currentIndustry || !DATA[currentIndustry]) {
    alert('Industry data not available. Please restart.');
    return;
}
```

### Chart Rendering
```javascript
// Check canvas exists
if (!canvas) {
    console.warn('Canvas element not found:', canvasId);
    return;
}

// Destroy existing chart
if (charts[canvasId]) {
    charts[canvasId].destroy();
}

// Try-catch wrapper
try {
    // Chart rendering logic
} catch (error) {
    console.error('Error drawing chart:', canvasId, error);
}
```
